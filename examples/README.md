# Example artwork

Choose the matching console tab, select **Add images…**, and open an import-ready PNG. The cartridge examples come from retail game cards. Perspective is corrected where needed, and the fitted images include room for bleed. The source and release region are listed for each game. [Full-size A4 sheets](../print/README.md)
