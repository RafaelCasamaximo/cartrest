# The Cartrest name

**Cartrest** combines *cart*, short for *cartridge*, with *rest*, a surface that supports a drink. It describes both the printed piece and the editor that helps finish it.

| Name | Meaning |
| --- | --- |
| **Cartrest** | A cartridge-shaped rest for a drink. The project name. |
| **Cartpad** | A pad for a cup, with a nod to mousepads. |
| **Cartmat** | A cartridge-shaped mat or tabletop accessory. |
| **Cartsip** | A playful combination of cartridges and drinks. |
| **Slotmat** | A tabletop mat with a nod to the Nintendo DS cartridge slot. |
| **Slotpress** | A name focused on the cartridge label and the printing process. |

**Short description**

A cartridge-shaped coaster with labels sized to fit.
