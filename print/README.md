# Print examples

Each set contains one label from Mario, Pokémon, Zelda, and Kirby. Cartrest exported the pages using the matching console profile at its nominal 100 mm coaster width. The dashed line is the final cut and the artwork extends 2 mm past it. [Import-ready game artwork and sources](../examples/README.md)

| Console | Cut size | A4 pages | Download |
| --- | --- | ---: | --- |
| Nintendo DS | 81.8 × 86.4 mm | 1 | [Cartridge labels](cartrest-cartridge-labels-a4.pdf) · [Box covers](cartrest-example-a4.pdf) |
| Nintendo 3DS | 77.35 × 81.70 mm | 1 | [Cartridge labels](cartrest-3ds-cartridge-labels-a4.pdf) |
| Nintendo Switch | 84.8 × 113.6 mm | 2 | [Cartridge labels](cartrest-switch-cartridge-labels-a4.pdf) |
| Nintendo Switch 2 | 84.8 × 113.6 mm | 2 | [Cartridge labels](cartrest-switch2-cartridge-labels-a4.pdf) |

1. Print on A4 paper at **Actual Size (100%)**.
2. Measure the **50 mm** reference ruler on the printed page.
3. Cut along the dashed line and test the fit in the recess. For a resized coaster, export the sheet from the same Cartrest tab and width used to save its STL.
